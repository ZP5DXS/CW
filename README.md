# CW — Free Morse Code Tools for the World

**CW** is a growing ecosystem of free tools created to help people **learn, practice, operate, listen to and enjoy Morse code**.

🌐 **Master site:** https://zp5dxs.github.io/CW/  
📡 **CW ON TV — Live 24/7:** https://www.youtube.com/live/Bhd8-vvPzFc  
👤 **Created by ZP5DXS · Paraguay**

---

## Why this exists

Morse code is more than a sequence of dots and dashes.

It is rhythm, concentration, patience, radio, friendship and the strange feeling of hearing a signal emerge from the noise and realizing that there is another person on the other side.

This project started from a very simple idea:

> **Make CW easier to discover, easier to practice and easier to enjoy.**

No paywalls. No complicated setup. No pressure to be fast.

Just tools that help people spend more time with CW.

Some users may be taking their first steps. Others may already be active operators. Some may want structured lessons, others just want to copy callsigns, listen to a continuous CW stream, simulate QSOs or see what is happening on the bands.

The goal of **CW** is to give all of them a place to start.

## The CW ecosystem

### 🎧 Morse Practice

A browser-based Morse code trainer for learning and practicing CW.

Practice with keyboard, mouse, touch, straight key or paddles. Includes learning modes, listening exercises, games, QSO practice, head-copy training and more.

**Open:**  
https://zp5dxs.github.io/morse-practice/

**Source:**  
https://github.com/ZP5DXS/morse-practice

---

### 🎙️ CW Studio

Create your own CW learning material.

CW Studio is designed to generate structured Morse code sessions, lessons and practice content, including audio and video material for personal training and educational use.

**Open:**  
https://zp5dxs.github.io/CW-Studio/

---

### 🌐 CW Network

A virtual CW radio experience.

CW Network recreates part of the feeling of operating HF: tuning, listening, transmitting and completing simulated CW QSOs in a radio-like environment.

It is not only a trainer. The idea is to make CW operation itself something that can be explored and practiced.

**Open:**  
https://zp5dxs.github.io/CW-network/

---

### 📡 CW LATAM

A live CW activity radar focused on the 40-meter band.

CW LATAM uses Reverse Beacon Network information to visualize real CW activity, stations, frequencies, signal reports and spotting activity.

It was created with Latin America in mind, while still showing the wider CW world around it.

**Open:**  
https://zp5dxs.github.io/CW-LATAM/

**Source:**  
https://github.com/ZP5DXS/CW-LATAM

---

### 📺 CW ON TV

A continuous Morse code learning and listening stream.

CW ON TV broadcasts CW lessons, familiarization sessions and practice material in **English and Spanish**, creating a place where someone can simply tune in and start listening.

**Watch live 24/7:**  
https://www.youtube.com/live/Bhd8-vvPzFc

**Morse Practice:**  
https://zp5dxs.github.io/morse-practice/

## Mission

To create **free, accessible and useful CW tools** that reduce the distance between curiosity and real Morse code operation.

The project should always remain approachable enough for a beginner, while still being interesting to someone who already uses CW on the air.

---

## Vision

A connected CW ecosystem where someone can:

**discover Morse → learn it → practice it → listen to it → simulate operating → go on the air → stay part of the community**

All from tools that work together.

The long-term idea is not to build one giant application.

It is to build several focused tools, each doing one job well, and connect them through a common home:

### https://zp5dxs.github.io/CW/

---

## Objective

The objective is simple:

**Help more people spend more time with CW.**

That can mean:

- learning a first character,
- completing a first lesson,
- copying a real callsign,
- understanding a QSO,
- making a first contact,
- returning to CW after many years,
- or simply enjoying Morse code as a language, skill and part of radio culture.

Every minute of useful practice matters.

---

## Community impact

The master CW site is being designed to show the impact of the complete ecosystem in one place.

Over time it will combine public statistics such as:

- total tool visits,
- countries reached,
- hours of CW practice,
- lesson usage,
- generated training material,
- simulated QSOs,
- CW ON TV activity,
- and other indicators of community participation.

The intention is not to turn CW into a competition.

The numbers are there to answer a much nicer question:

> **How much CW did we help create together?**

---

## Free by design

These projects are built first as a contribution to the amateur radio and CW community.

Wherever possible, the tools are designed to remain:

- free to use,
- easy to access,
- lightweight,
- browser-based,
- multilingual,
- and useful without unnecessary registration.

Some projects are also published openly on GitHub so others can inspect, learn from, improve or reuse the work.

---

## A personal note

I am not building these tools because I believe CW needs to be reinvented.

CW does not need to be reinvented.

It has already survived generations of technology.

What I do believe is that **the path into CW can always be made a little easier, more welcoming and more interesting**.

If one of these tools helps someone recognize their first character, finish their first QSO, return to radio, practice five more minutes, or simply become curious about Morse code, then the project already did something worthwhile.

This ecosystem will keep evolving as long as it remains useful and enjoyable to build.
